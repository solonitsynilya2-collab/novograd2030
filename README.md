# Новоград 2030 — Прорыв дамбы

Командная учебная симуляция на основе предоставленного HTML. До 50 участников в одной игре, пять ролей, три хода по два раунда Delphi, финальное взвешенное сравнение проектов.

## Работа с игрой

1. Ведущий открывает вкладку «Ведущий», вводит секретный ключ и создаёт игру.
2. Участники вводят код игры, имя и назначенную команду. Сохраняют личный код для повторного входа.
3. Ведущий переключает этапы. Ответы сохраняются на сервере после отправки; до конца этапа их можно изменить.
4. После финала показываются рейтинг проектов и рейтинг полноты участия: 10 баллов за каждый раунд, 40 за финал. Максимум 100; равные результаты получают одинаковое место.
5. Ведущий может выгрузить участников и все ответы в JSON.

## Данные и доступ

Cloudflare D1 через Sites: таблицы rooms, players, answers. Имена уникальны внутри игры без учёта регистра; идентификаторы UUID. Личные коды хранятся в базе только в виде SHA-256. Ключ ведущего задаётся серверной переменной ADMIN_KEY. Ни ключи, ни ответы не хранятся в GitHub. В браузере sessionStorage содержит текущий код входа; для другого устройства используется личный код. Общий экран показывает анонимные аргументы; ведущий видит связь ответов с участниками при экспорте.

## Разработка

Node.js >=22.13.0. `npm ci`, `npm run db:generate`, `npm run build`, `npm run dev`. Для локальной базы применить сгенерированную миграцию через Wrangler D1 (см. scripts). Секрет ADMIN_KEY задавать через локальный .dev.vars, который исключён из Git.

Сайт и база развёртываются в Sites; GitHub хранит исходники. Изменение GitHub само по себе не публикует новую версию — нужна сборка и публикация в Sites.

## Отличия от исходника

Ответы учитываются по участнику, а не по команде. Этапы и права проверяются сервером. Убраны публичный сброс и доступ к управлению без ключа. Вместо неограниченного размножения таймеров — один опрос состояния раз в 5 секунд. Ошибки соединения видны, подтверждение сохранения появляется только после ответа базы.

Сценарий не содержит объективной модели последствий для каждого решения; приложение не выдаёт средний балл поддержки за доказательство безопасности. Итоговое сравнение — взвешенная сумма, а не полный метод AHP с попарными сравнениями.

## Проверки

`node tests/api.mjs` — интеграционный тест обработчика на SQLite: права ведущего, изоляция игр, два участника в одной команде, повторная отправка, валидация, весь цикл и лимит 50 человек. `npx tsc --noEmit` — типы.
