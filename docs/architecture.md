# Архитектура

Браузер → POST /api/game → Cloudflare D1. Сервер подтверждает сохранение до сообщения об успехе. Чтение текущего этапа каждые 5 секунд. Незавершённая форма не перезаписывается опросом.

Ведущий: секрет ADMIN_KEY в окружении, создание комнаты, открытие этапа, экспорт. Участник: случайный 128-битный личный код, хеш SHA-256 в базе. Комната и код проверяются вместе на каждом запросе.

Этап 0: регистрация; 1–6: три хода × два раунда; 7: восстановление; 8: итоги. Обновление этапа условное, повторный клик не пропускает следующий этап. Запись ответа также проверяет открытый этап внутри SQL.

Уникальные индексы: room + normalized (имя), player + step (ответ). Вставка нового участника проверяет лимит 50 и открытую регистрацию в одном SQL. Ответы одного участника обновляются, ответы остальных не затрагиваются.

Экспорт содержит идентификаторы, имена, команды и ответы; не содержит личных кодов или их хешей. Публичный рейтинг доступен только участникам соответствующей игры после завершения; тексты аргументов показываются без имён на завершённых этапах.

Рейтинг проектов: средняя по участникам сумма (вес критерия × оценка) / 100. Рейтинг участия: 6 × 10 + 40 = 100. Это учебная симуляция без оценки профессиональной пригодности и без объективной модели ущерба.

Известные ограничения: нет восстановления потерянного личного кода, нет электронной почты/Telegram-авторизации, нет автоматического переноса новых коммитов GitHub в Sites. Нужен доступ к сети. JSON выгрузку хранит ведущий.
