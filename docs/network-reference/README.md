# Новоград 2030 — сетевая версия

## Запуск

Требуется Node.js 18+.

```bash
npm start
```

Откройте `http://localhost:3000` на компьютере ведущего.

Для телефонов в той же Wi‑Fi сети используйте IP компьютера ведущего, например:
`http://192.168.1.42:3000`

Если Windows/macOS спрашивает разрешение firewall — разрешите входящие подключения Node.js для частной сети.

## Как играть

1. Ведущий нажимает «Создать сессию».
2. Ведущий раздаёт участникам код сессии и их личные коды.
3. Ведущий управляет ходами с пульта.
4. Участники голосуют со своих телефонов.
5. Сервер хранит ответы и рассылает агрегированное состояние всем подключённым клиентам.
6. На общем экране не показываются личные коды и фамилии.

## Демо-коды

При создании каждой сессии сервер генерирует новые коды. Они показываются ведущему.

## Важно

Это MVP без базы данных и авторизации администратора за пределами секретного ключа: данные живут в памяти процесса и исчезают после перезапуска Node.js. Для реального занятия с несколькими группами стоит добавить PostgreSQL/SQLite, HTTPS и постоянные сессии.
